## Sample Pseudocode: Decimal to Binary

```text
START
INPUT n
SET binary = "0"
IF n > 0 THEN
    SET binary = ""
    WHILE n > 0 DO
        SET remainder = n MOD 2
        SET binary = remainder + binary
        SET n = n DIV 2
    ENDWHILE
ENDIF
DISPLAY binary
END
```
